# Gépi tanulás alapjai – féléves projekt

Magyar lakóingatlanok árának (vagy négyzetméterárának) előrejelzése regressziós
gépi tanulási modellekkel, az ingatlan jellemzői (méret, elhelyezkedés, szobaszám,
állapot stb.) alapján.

## Jelen állapot

A projekt jelenleg a tervezési fázisban van, kód még nincs. Nyitott kérdés az
adatforrás (saját scraping vs. meglévő adatkészlet) és néhány más döntés is –
ezeket lásd a `plan.md`-ben.

## Dokumentumok

- [`plan.md`](plan.md) – a projekt részletes terve: probléma, adatforrás
  lehetőségek, előfeldolgozás, módszertan, ütemterv, nyitott döntések.
- [`projekt_javaslatok.md`](projekt_javaslatok.md) – oktatói/értékelési
  szempontok és a dokumentáció javasolt struktúrája.

## Tervezett eszközök

Python (pandas, numpy, scikit-learn, matplotlib/seaborn, esetleg
xgboost/lightgbm), Jupyter notebook a feltáró elemzéshez, Git a csapatmunkához.
